Монгол Keyboard бол iOS-д зориулсан гар: латинаар бичээд зай дарахад үг тань кирилл болж хувирна — бүгд төхөөрөмж дээрээ. АБВ горимоор кирилл үсгээр шууд бичиж болно; гар интернэт огт ашиглахгүй.

An iOS keyboard for Mongolian: type Latin and each word turns Cyrillic at the space — all on-device. An АБВ mode types Cyrillic directly, and the keyboard never goes online.

Зай дарахад үг бүтнээрээ хөрвөнө: sain→сайн (эгшгийн дараах i→й), sh→ш, ts→ц, ухаалаг эгшиг unoodor→өнөөдөр — бүгд төхөөрөмж дээр, сүлжээгүйгээр.

Суулгах / Install

Гурван алхамд бэлэн

  1. Гараа нэм Settings → General → Keyboard → Keyboards → Add New Keyboard… → Монгол Keyboard Add the keyboard in iOS Settings.
  2. 🌐 товчоор сонгоод бич Аль ч апп дотор 🌐 товчоор Монгол Keyboard-г сонгоод sain baina uu гэж бичээд үзээрэй. Switch with the 🌐 key and start typing.
  3. (Заавал биш) “Allow Full Access” Ганцхан зүйлд хэрэгтэй: гарын цээжилсэн үгсийг апп дотроо харж, засаж, арилгах. Бичих, хөрвүүлэх, сонголтын мөр, үг цээжлэх нь үүнгүйгээр ч бүрэн ажиллана. Гар интернэт огт ашиглахгүй. Optional, for one thing only: seeing and managing the keyboard's learned words in the app. Typing, conversion, the candidate bar and learning all work without it, and the keyboard never goes online.
